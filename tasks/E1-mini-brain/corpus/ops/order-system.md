# 订单系统状态说明

> 适用人员：所有门店与工厂人员。最后修订：2026-03-15。

## 状态机

```
待量房 → 待设计 → 待签约 → 待生产 → 生产中 → 待安装 → 已完成
                                                  ↘ 售后中 ↔ 已完成
任一状态 → 已取消
```

| 状态 | 含义 | 进入条件 |
|---|---|---|
| 待量房 | 线索转订单但未量房 | CRM 线索签约前预建（少见） |
| 待设计 | 量房完成 | 量房单上传 |
| 待签约 | 方案已出 | 设计师标记方案已发送 |
| 待生产 | 合同已签、首付到账 | 收银确认首付 |
| 生产中 | 拆单通过 | 工厂计划确认 |
| 待安装 | 生产完成 | 工厂标记出库 |
| 已完成 | 验收单签字 | 安装组长上传验收单 |
| 售后中 | 有未关闭的售后单 | 售后专员创建售后单 |
| 已取消 | 客户取消或合同终止 | 店长操作 |

## 关键字段

- 订单号：格式 `YQ-门店代码-年月-序号`，例如 `YQ-CD-2607-0031`（城东店 2026 年 7 月第 31 单）
- 预计完工日：拆单通过日 + 生产周期（标准 25 天 / 旺季 35 天），系统自动算，不允许手改
- 付款记录：定金、首付、尾款分别记录，尾款未清系统不允许进入「待安装」
- 活动编号：报价时引用，系统校验活动时间窗口

## 生产进度

「生产中」状态下可展开看阶段：拆单审核 / 开料 / 封边 / 打孔 / 门板 / 包装 / 已出库。门店回复客户进度只能引用这些阶段。

## 补件

「待安装」或「已完成」状态下，安装组长或售后专员可发起补件单，工厂 3 个工作日内发出。补件单关联原订单号，免费；因设计错误的补件系统会标记责任门店。

## 权限

| 角色 | 能做什么 |
|---|---|
| 门店客服 | 查看订单、创建售后单与投诉单 |
| 设计师 | 发起合同、拆单、变更单 |
| 店长 | 取消订单、审批折扣、判定质保 |
| 安装组长 | 上传现场照片、验收单、发起补件 |
| 工厂计划 | 确认拆单、更新生产阶段、标记出库 |
| 系统管理员 | 全部 + 系统设置（含飞书通知，见 `ops/lark-bot-setup.md`） |

## 导出

订单系统每天 07:30 把当日库存快照导出到知识库 `daily/inventory.md`；报表导出需店长以上权限，导出文件带水印。
