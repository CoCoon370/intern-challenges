# CRM 字段与线索状态说明

> 适用人员：门店客服、设计师、运营。最后修订：2026-04-22。

## 线索状态流转

```
新线索 → 已联系 → 已量房 → 已出方案 → 已签约
                 ↘ 流失（任一阶段可进入）
```

| 状态 | 进入条件 | 谁改 |
|---|---|---|
| 新线索 | 系统自动创建或人工录入 | 系统 / 客服 |
| 已联系 | 首次电话或到店接待完成 | 客服 |
| 已量房 | 量房单上传 | 系统自动 |
| 已出方案 | 首版方案发送 | 设计师 |
| 已签约 | 订单系统合同签署完成 | 系统自动 |
| 流失 | 30 天无跟进，或客户明确放弃 | 客服 / 系统 |

「新线索」超过 **24 小时**未变为「已联系」会推送提醒给门店店长。

## 必填字段

| 字段 | 取值 | 说明 |
|---|---|---|
| 来源 | 门店 / 小程序 / 转介绍 / 平台 / 社区活动 | 转介绍必须填推荐人订单号 |
| 门店 | 城东店 / 城西店 / 滨江店 | 按客户就近分配 |
| 意向产品 | 衣柜 / 橱柜 / 榻榻米 / 全屋 | 可多选 |
| 预算区间 | <2 万 / 2–5 万 / 5–10 万 / >10 万 | 客户口述即可 |
| 装修阶段 | 未开工 / 水电中 / 泥木中 / 已完工 | 影响量房时机 |
| 联系方式 | 手机号 | 系统脱敏显示，只有分配的客服可见完整号码 |

## 隐私规则

- 客户手机号在 CRM 内脱敏显示（中间四位隐藏），完整号码只对当前跟进人可见
- 不允许把客户信息导出到个人设备
- 客户要求删除信息的，客服在 CRM 提交删除申请，系统管理员 3 个工作日内处理

## 跟进记录

每次联系必须写跟进记录，至少包含：联系方式（电话/到店/线上）、客户反馈、下一步动作与时间。跟进记录是店长周会的依据。

## 与订单系统的关系

线索签约后，CRM 自动在订单系统创建订单并把线索 ID 写入订单。之后的进度在订单系统看，CRM 只保留线索阶段的记录。订单状态说明见 `ops/order-system.md`。

## 日报

CRM 每天 07:30 自动导出前一日线索汇总到知识库 `daily/leads.md`，用于晨会，数字不作为考核依据。
