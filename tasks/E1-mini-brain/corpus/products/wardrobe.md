# 衣柜产品线说明

> 适用范围：全屋定制业务中的独立衣柜、入墙衣柜、衣帽间。最后修订：2026-07-12。

## 柜体与板材

衣柜柜体默认使用 **ENF 级实木颗粒板**，厚度 18mm，背板 9mm。ENF 是目前国内最高的板材环保等级，甲醛释放量 ≤ 0.025 mg/m³；E0 级（≤ 0.050 mg/m³）作为门板与部分饰面的备选等级。

客户可以按整柜升级柜体材质：

- **多层实木板**（ENF 级）：适合南方潮湿地区或对握钉力有要求的场景
- **欧松板**（E0 级）：主要用于榻榻米底箱与承重层板，衣柜整柜不建议

三种板材的对比与检测标准见 `products/boards.md`，升级差价见 `pricing/wardrobe-pricing.md`。

## 标准尺寸与限制

- 标准高度 ≤ 2,400mm；2,400–2,700mm 属超高，需要拼接顶柜，报价按超高规则加收
- 标准深度 600mm（挂衣区），550mm 为最小可接受深度
- 单块层板跨度 ≤ 900mm，超过需加竖隔板或使用 25mm 厚层板
- 推拉门单扇宽度 ≤ 1,200mm；平开门单扇宽度 ≤ 600mm

## 门板选项

| 门型 | 默认材质 | 说明 |
|---|---|---|
| 平开门 | E0 多层实木 + 三聚氰胺饰面 | 默认选项，配铂锐阻尼铰链 |
| 推拉门 | 铝框 + 板材/玻璃 | 铂锐上下轨，含防跳装置 |
| 无门（开放式） | — | 衣帽间常用，价格按柜体计 |

## 内部配置

标配：挂衣杆 ×2、活动层板 ×4、抽屉 ×2（铂锐三节静音滑轨）。可加购：裤架、领带盒、旋转穿衣镜、感应灯带。所有加购件单价见报价文档，不在本文件维护。

## 设计注意事项

1. 顶柜与顶面之间留 20mm 收口，走线或不平整时用封板处理
2. 靠窗一侧必须留 ≥ 50mm 间隙给窗帘盒
3. 儿童房衣柜抽屉一律安装防夹手缓冲，不接受客户取消
4. 设计稿必须标注板材等级与五金型号，否则拆单不予通过
